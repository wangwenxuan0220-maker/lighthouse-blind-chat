# 灯塔 · 原来是你（本地测试版）

## 运行

需要 Node.js 22 或以上。在此目录运行 `npm ci` 和 `npm start`，打开 http://localhost:8787 。话题盲盒位于 `/topics/`，为独立的540题新版，旧版线上500题尚未替换。

活动创建后分享参与者入口；主持人在原浏览器标签页操作。主持人也想参加时，另开浏览器/无痕窗口通过参与者入口加入。默认不分桌；桌名一行一个，无人数下限或固定人数档位。昵称必填，其余身份信息可跳过。

本地二维码中的 localhost 只能在当前电脑使用，不能冒充公网扫码入口；手机局域网测试需要以电脑的局域网IP访问，并确保设备在同一网络。正式扫码需要部署后的 HTTPS 网址。

## 数据生命周期

身份、句子、主持人和桌长权限只保存在单个 Node.js 进程内存中，无数据库、无身份日志。活动结束或创建12小时后服务端清空；服务重启也清空。在线客户端每2秒同步，接到结束状态后清空内容和sessionStorage凭证，离线客户端无法即时获知提前结束，但会在本地到期或恢复连接时清空。参与者自行保存的截图无法撤销。平台本身可能保留访问日志。

同一标签页刷新可恢复身份，关闭标签页后不承诺恢复。新一轮清空句子、保留身份；不提供历史活动回看。揭晓前接口不向其他人发送作者映射。分桌由服务端按参与者所属桌过滤；主持人可看全场，桌长只可揭晓本桌。

## 免费托管

`render.yaml` 为 Render Free 单实例配置，不创建数据库。首次部署需要 Render 账号并授权本仓库。本目录应作为独立仓库根目录发布（不要上传 node_modules、测试截图或整个个人工作区）。免费服务可休眠/重启，内存活动会丢失；正式活动前需要在实际手机、微信、活动网络试用。不设置付款方式；若账号要求绑卡验证则暂停，不默认升级。

## 验证

`npm test`：匿名映射、分桌权限、普通用户无法揭晓/结束、锁定修改、新轮次、撤回、活动结束及到期失效、50人加入、540题结构及旧进度隔离。

`node browser-test.mjs`：本机隔离 Chrome 主持人+两个手机窗口，验证加入、刷新恢复、分桌、匿名墙、揭晓、结束远端清空和540题抽卡。脚本使用本机Playwright路径，不是网站运行依赖。
